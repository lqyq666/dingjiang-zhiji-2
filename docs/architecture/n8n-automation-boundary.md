# n8n 自动化边界

## 允许

- 基于已提交业务事件触发通知。
- 确定性定时任务、重试、同步与 ETL。
- 调用版本化 Integration API 或专用 Connector Interface。
- 写入前携带幂等键、correlationId 和明确 actor，并服从 API 授权。

## 禁止

- 把 n8n 当作业务事实源、审批引擎、Agent 记忆或领域状态机。
- 在流程节点中直接连接生产 PostgreSQL 或绕过 RLS。
- 用大模型节点替人作出方案定稿、事项完成、结果确认或经验发布决定。
- 在工作流定义中保存令牌、数据库密码或用户敏感信息。
- 将 HTTP 200 或流程完成解释成业务验收完成。

## 失败与恢复

通知和同步失败不得回滚已经成立的业务事实。失败记录必须关联 correlationId；付费或外部调用最多自动重试一次，仍失败转人工处理。补偿动作通过 API 追加审计，不直接改写历史。

## Phase 1 状态

仅冻结边界，不创建、不发布、不运行任何真实 n8n 工作流。
